What none of this establishes. The model was trained and tested on {{ test.provenance.dataset.images }} public radiographs from two archives, with no Kenyan data and no prospective study against a microbiological reference standard. It is not a medical device, it is not clinically validated, and it is not registered with any regulator. These figures describe a research prototype on public data, which is a different claim from the one a deployed screening tool would need to make.
